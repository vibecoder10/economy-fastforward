# Image-selection public-source receipts

Eight public pages were consulted: five Commons file pages and three Naval History and Heritage Command ship histories.

| Vessel | Retrieved image records | Explicit membership evidence |
|---|---|---|
| USS Albacore (AGSS-569) | Two distinct Commons records: 1957 underway (739 × 554) and 2016 Portsmouth museum exterior (2688 × 1520). | Not applicable to the requested Barbel-class membership set; no membership claim recorded. |
| USS Barbel (SS-580) | One Commons launching record, 19 July 1958 (900 × 720). | [NHHC DANFS Barbel II](https://www.history.navy.mil/research/histories/ship-histories/danfs/b/barbel-ii.html): “SS-580 ... class Barbel.” |
| USS Blueback (SS-581) | One Commons underway side-profile record, circa 1981 (1662 × 401). | [NHHC DANFS Blueback II](https://www.history.navy.mil/research/histories/ship-histories/danfs/b/blueback-ii.html): “SS-581 ... cl. Barbel.” |
| USS Bonefish (SS-582) | One Commons port-side underway record, 1980-81 (800 × 563). | [NHHC DANFS Bonefish II](https://www.history.navy.mil/research/histories/ship-histories/danfs/b/bonefish-ii.html): “SS-582 ... cl. Barbel.” |

The full candidate metadata, source-page URLs, Commons file-path URLs, captions, dimensions, and missing-evidence fields are in [image-selection-candidates.json](image-selection-candidates.json).

Remaining gaps: the eight-page bound did not allow two file pages for each Barbel-class vessel. No membership was inferred from visual similarity; every listed Barbel membership claim is directly tied to its NHHC history page.
