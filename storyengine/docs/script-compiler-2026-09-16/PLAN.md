- compile_script_packet(machine, source_package, assessment, candidates, *, subject_context='', episode_outline=None, current_briefing=None, model='') -> dict. Exclude non-supported claims from selected facts but retain compact exclusions/status/reason, never their evidence text.
- Fact category deterministic rule: explicit allowed category if supplied, otherwise case-insensitive keyword match in claim+scope, priority identity(type/class/named/designated), purpose(designed/intended/role/purpose), design(engine/hull/armament/power/displacement/speed/range/deck/propulsion/torpedo), service(commission/served/operation/patrol/battle/war/deploy), outcome(decommission/scrap/sunk/lost/retire/museum), other. Match specific outcome, purpose, design, service before broad identity when multiple match, then emit in category order identity/purpose/design/service/outcome/other. This classification is presentation only; never change historical text. Select <=8 facts, first one per available category, then fill in category order; tie by best source_tier numeric (missing=99), fact_id. Canonically sort all sets/maps for stable hash; roster outline order remains authoritative.
- Each fact includes fact_id, assessment_claim_id, category, claim, scope, evidence list. Each evidence contains original excerpt_id, exact quote, source_url/source_id/source_title/locator/source_capture_method/source_tier copied from eligible candidate, no model-authored metadata. Validate quote is exact substring of candidate text and supplied evidence URL if present equals candidate URL. Keep each fact's ALL evidence rows as an indivisible unit to preserve corroboration; deduplicate exact evidence pairs; no slicing quote or evidence. Oversized whole fact excluded with reason; if none fit, ScriptPacketError. Full ledger/archive remains on original research card. Keep compact excluded claim metadata bounded (status, ID, reason code, no giant reason fields).
- Packet outline whitelist only scene integer and machine string, max128 entries; machine/title/scope/paragraph metadata over sane explicit length caps must fail closed, not slice. Outline machine max240 chars; subject max1000 chars; machine max240 chars; briefing paragraph max2000 chars. Current briefing is optional wording reference ONLY: include paragraph only and never claim_map/sources/assessment. No detail from other briefings permitted. If base metadata alone cannot fit, fail. Selection incremental: candidate full fact must fit JSON serialized compact UTF8 <=MAX_PACKET_BYTES including selection metadata; skip whole oversized fact, return exclusion receipt. Packet selected facts in category order, deterministic fact IDs/order, evidence and identity. Include compiler_version/prompt_rules_version, model, subject_context, machine, outline, current_briefing, facts, excluded_claims, source_fingerprint and packet_fingerprint. packet_fingerprint hashes all rules/version/model/current input content/outline plus complete package digest. stable for dictionary insertion ordering and claim/evidence-list reorder; changing actual source, rules/model/outline changes fingerprint. Include packet byte size as receipt field if useful (avoid self-dependent fingerprint).
- materialize_script_draft(raw: dict, packet: dict) -> dict. Validate nonempty claim_map list and each row has nonempty unique fact_ids all selected. Rebuild each row citations solely by union of exact evidence on referenced facts, in canonical order; reject model-supplied citation mismatch? Preferred ignore citations entirely and build authoritative ones; never trust model-supplied provenance. Preserve sentence and fact_ids in returned rows. Do not infer facts from arbitrary sentences. Mechanical sentence coverage and factual entailment remain downstream. Unknown/missing fact IDs fail ScriptPacketError. No source mutation.
- assert_request_budget(prompt, system_prompt, max_tokens) -> dict. Deterministic conservative input token upper bound = UTF8 byte length of prompt+system +1024 framing allowance. Require <=48000 and upper bound+max_tokens<=200000; on failure ScriptPacketError. Return method='utf8_byte_upper_bound', input_token_upper_bound, output_tokens_reserved, context_limit; never label as exact tokenizer count. This stricter cap obviates provider count calls and handles long/unicode excerpts. Do NOT silently trim a assembled request. Call immediately before all writer/referee model generate calls in factual_machine_summary (research too, same byte safety but no behavior rewrite).
