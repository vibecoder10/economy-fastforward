# Repurposing Chain — Video Artifacts → 3 Platform Promotions

> This is NOT "give me a topic and I'll write for 3 platforms."
> This is "here's a video with research, script, hook, SEO data,
> and performance learnings — generate 3 genuinely different pieces
> that each promote the video from a different angle."

## The Chain Order

Write in this order. Each step builds on the previous but
approaches the topic from a DIFFERENT angle.

### Step 1: [[x]] (Write First — The Sharp Point)

X forces brevity. Starting here makes you find the SINGLE most
compelling data point from the entire research payload.

**Input:** research payload + video hook + SEO keywords + title
**Process:**
1. Scan research payload for the most shocking/contrarian stat
2. Match to a [[hooks]] formula based on the video's curiosity gap structure
3. Write the hook line (under 280 chars)
4. If thread: add 5-8 evidence points from research
5. If short take: hook + one stat + punchline

**Output:** one tweet/thread (280-2,000 chars)
**Angle:** the SHARPEST single point from the research

### Step 2: [[linkedin]] (Expand — The Investigation Story)

Take the X post, but DON'T just add words. Change the ANGLE.

**Input:** X post + research payload + script Acts 1-2 + channel profile
**Process:**
1. X gave us the sharp point → LinkedIn tells the INVESTIGATION STORY
2. Open with personal framing: "I spent [time] tracking [topic]..."
3. Walk through the evidence chain (adapted from script narrative)
4. Close with professional implication: what this means for
   [industry/market/policy]

**Output:** long-form post (1,300-2,000 chars)
**Angle:** the INVESTIGATION JOURNEY — how you found this, why it matters

**What changes from X:**
| Element | X Version | LinkedIn Version |
|---------|-----------|-----------------|
| Hook | Contrarian stat | Personal investigation opener |
| Tone | Casual + punchy | Authoritative + narrative |
| Depth | Single sharp point | Full evidence chain |
| CTA | "full investigation [link]" | Discussion question |
| Framing | "here's what they're hiding" | "here's what I found" |

### Step 3: [[newsletter]] (Deepen — The Intelligence Briefing)

The newsletter gets what neither social platform got: DEPTH.

**Input:** ALL pipeline artifacts (full research, full script, cut material)
**Process:**
1. Open with behind-the-scenes: what triggered this investigation
2. Include data and context that was cut from the video for time
3. Show your analytical process: "I looked at X, then Y, then
   the pattern became clear..."
4. Include genuine uncertainty: what you don't know yet
5. Close with what you're watching next

**Output:** 1,000-2,000 word email section (or full issue for big topics)
**Angle:** the FULL PICTURE — exclusive depth, methodology, uncertainty

**What changes from LinkedIn:**
| Element | LinkedIn Version | Newsletter Version |
|---------|-----------------|-------------------|
| Hook | Investigation opener | Insider briefing tone |
| Depth | Key evidence chain | Full analysis + cut material |
| Tone | Professional authority | Intimate intelligence |
| Vulnerability | None | "I'm uncertain about..." |
| Exclusivity | None | Research that didn't make the video |
| Length | 1,300-2,000 chars | 1,000-2,000 words |

## The Litmus Test

Each platform version should pass this test:

"If someone followed me on ALL platforms, would they be
annoyed seeing the same thing everywhere?"

If yes → you're reformatting, not rethinking. go back.
If no → you've made 3 genuinely different pieces from one video.

**Stronger test:** Would each piece be valuable EVEN WITHOUT
the video? The X post should stand alone. The LinkedIn post
should stand alone. The newsletter should stand alone. They
promote the video, but they're not dependent on it.

## Batch Workflow

### Per Video (publish day)

1. Video finishes upload pipeline
2. Pull all artifacts: research, script, hook, SEO, title structure
3. Check Osiris for relevant learnings (which hooks worked recently)
4. Write X post → LinkedIn post → newsletter section (in order)
5. Review all 3 together — ensure angles are genuinely different
6. Schedule per [[scheduling]] relative to video publish time

### Weekly Newsletter

1. Gather all video topics from the week
2. Pick the BEST topic for the deep-dive section
3. Add 1-2 data points from other videos as quick mentions
4. Include "what I'm watching" from upcoming research/discovery

## What Actually Changes Between Platforms

| Element | How It Adapts |
|---------|--------------|
| Angle | Sharp point → investigation story → full analysis |
| Hook | Stat/contrarian → personal "I found" → insider briefing |
| Tone | Casual urgency → professional authority → intimate intelligence |
| Depth | Surface + proof → medium + narrative → deep + methodology |
| Length | 280-2000 chars → 1300-2000 chars → 1000-2000 words |
| Exclusivity | None (public) → None (public) → Cut material + uncertainty |
| CTA | Watch video → Discuss → Reply/share |

## Anti-Patterns

- Posting the YouTube description on X. that's not promotion, that's spam
- Posting the same hook on all 3 platforms. different platform = different hook
- Making the newsletter a "watch my new video" email. it must have standalone value
- Ignoring performance data. if proof hooks get 2x engagement on X, use more proof hooks
